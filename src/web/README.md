# Heady Web Frontend

React + Vite frontend for the Heady dashboard.

## Setup
```bash
cd src/web
npm install
npm run dev
```

## Build
```bash
npm run build
```

Output goes to `dist/` which is served by the Express backend or deployed to Cloudflare Pages.
