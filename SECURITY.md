# Security Policy

## Supported Versions

The Heady Latent OS is continuously deployed. Security patches are applied to the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < `main`| :x:                |

## Enterprise Tier Security

This repository is governed by the HeadySystems GitHub Enterprise Account. Advanced Security (GHAS) including Secret Scanning and CodeQL is enforced.

## Reporting a Vulnerability

Because Heady involves sovereign agent orchestration, strict boundaries must be maintained between domains. If you discover a security vulnerability, please do NOT report it by creating a public GitHub issue.

Please report vulnerabilities directly to the core engineering team. 

**Response Time:**
You can expect an acknowledgment within 24 hours of receiving the report. We will triage and provide a timeline for remediation. 

**Bounty:**
At this time, there is no formal bug bounty program, but high-impact reports concerning Agent Escape, Vector Memory Poisoning, or Privilege Escalation (CSL Bypass) will be reviewed by the Founder.
