# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

- Email: security@headyconnection.org
- Do NOT open a public GitHub issue

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |

## Security Standards

This project follows enterprise security standards including:
- Automated secret scanning with push protection
- CodeQL static analysis on all PRs
- Required pull request reviews
- Signed commits encouraged
- Dependency audit via Dependabot
