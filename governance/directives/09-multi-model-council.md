# DIRECTIVE 9: MULTI-MODEL COUNCIL — COMPETITIVE AI ROUTING

## Purpose
Route AI tasks across providers/models by task type, cost, latency, quality. No single model answers
everything. The best model for the job wins. All provider traffic egresses through the Cloudflare AI Gateway.

## The Model Council (representative)
Claude Opus/Sonnet (deep reasoning, code, long context) · GPT-5 / o-series (deep agentic, formal logic) ·
Gemini Pro (multimodal, long-context) · Groq Llama (ultra-fast routine) · Perplexity Sonar (real-time web
+ citations) · Cloudflare Workers AI / LFM2 (edge classification, embed). Reserve frontier providers for
explicit `class=reason` / `class=longctx`.

## Routing Logic
CSL-scored (intent vector vs capability vectors) · cost-aware (budget tracker pre-call) · latency-aware
(edge for <100ms) · quality-aware (HIGH/CRITICAL → Council) · fallback chain workers-ai → cloud-run →
colab with per-provider circuit breaker.

## Council Mode (critical decisions)
Same prompt → 3+ models → score against each other → agreement = high-confidence → disagreement flagged →
synthesized response combining strongest elements.
