# DIRECTIVE 8: CONTINUOUS LEARNING & PATTERN EVOLUTION

## Purpose
Heady gets smarter with every task. Patterns are extracted, stored, scored, reused. Mistakes are recorded
and prevented from recurring. Effective intelligence increases monotonically.

## Learning Sources
Arena results (winners + losers) · error patterns (root cause + resolution) · performance metrics · user
preferences (implicit + explicit) · external intelligence (Perplexity research, red-team findings).

## Pattern Storage
`wisdom.json` (fast cache) · vector memory (semantic similarity) · Graph RAG (relationships) · HeadyVinci
(surfaces historical patterns).

## Anti-Regression Protocol
On recurrence: check `wisdom.json` → if found apply + log "pattern hit" → if not, solve from scratch +
add → if pattern solution fails, investigate drift, update pattern, log anomaly.
