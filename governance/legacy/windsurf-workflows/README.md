# governance/legacy/windsurf-workflows/ — Windsurf-Era Workflow Corpus

## Provenance

Archived Windsurf/Cascade-era workflows from the legacy Heady repo, snapshot **2026-06-08**
(`/home/headyme/_archive/Heady_20260608_102426/.windsurf/workflows/`), transferred into the
rebuild repo **2026-08-09** during the rebuild command consolidation. 41 files, preserved verbatim.

`heady-scan-workflow.md` and `claude-scan-workflow.md` are a known alias pair — identical except
for the self-referential `FILE:` line in each file's brand header; both are preserved.

## Status

**Historical reference only.** These are in the Windsurf workflow format (with `// turbo`
auto-execution directives) and are **NOT** wired as Claude Code commands — active commands live in
`.agents/workflows/` → `.claude/commands/`. The HCFP-era protocols here are superseded by the
rebuild's build-plan method (`tooling/build-plan`), the governance gate
(`tooling/governance-gate`), and `REBUILD_PLAN_V2`, but they remain the primary sources for the
HCFP 21-stage lineage and several operational patterns (error recovery, PDCA, zero-defect,
checkpoint sync).

> **Locked fact:** HCFullPipeline is canonically **21 stages (0–20)**. Some of these historical
> files may state a different stage count; they are preserved verbatim as historical record and
> must not be treated as authoritative on this point.
