# @heady-ai/phi-math

Shared φ, Fibonacci, CSL, and vector helper primitives.

## Highlights

- φ and ψ constants
- Fibonacci sizing helpers
- CSL score bands and labeling
- cosine similarity, normalization, centroid, and spatial distance helpers
- φ-weighted blending and backoff helpers
