Intelligent Orchestration

HCFullPipeline runs in strict dependency order with checkpoints at each stage. The system deeply re-analyzes state, configs, and patterns at every checkpoint.

Multi-Agent Supervisor

JULES, OBSERVER, BUILDER, ATLAS, and PYTHIA work in parallel fan-out. Tasks routed via direct routing with no proxy for minimal latency.

Circuit Breakers

Resource policies enforce concurrency limits, cost budgets, retry/backoff, and circuit breakers on all external calls. Production-grade resilience.

Operational Readiness

Continuous ORS scoring (0-100) determines system mode: full parallelism above 85, normal at 70-85, maintenance at 50-70, recovery below 50.

Checkpoint Protocol

Validate run state, compare config hashes, re-evaluate health, check concept alignment, sync registry, and produce comprehensive reports.

YAML-Driven Config

All pipeline definitions, resource rules, governance policies, and concept indexes live in versioned YAML configs. Deterministic given same inputs.
