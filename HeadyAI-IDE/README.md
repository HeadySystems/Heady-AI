# HeadyAI-IDE 🧠

## Next Generation AI-Powered Development Environment

HeadyAI-IDE is a cutting-edge development environment that integrates Heady AI models directly into your coding workflow. Built on Windsurf Next architecture with sacred geometry design principles.

### ✨ Features

- 🧠 **Heady Brain Integration** - Advanced AI assistance with multiple model options
- 🎨 **Sacred Geometry UI** - Beautiful, organic interface with animated patterns
- ⚡ **Real-time AI Collaboration** - Seamless AI assistance while coding
- 📁 **Smart File Management** - Intelligent project organization
- 🔧 **Monaco Editor** - Professional code editing experience
- 🎯 **Model Selection** - Choose from Heady Brain, Conductor, Pattern, and Critique models
- 🌟 **Animated Backgrounds** - Flower of Life and Metatron's Cube patterns

### 🚀 Available AI Models

1. **Heady Brain** - Primary AI model for general coding assistance
2. **Heady Conductor** - Task orchestration and workflow management  
3. **Heady Pattern** - Code pattern recognition and analysis
4. **Heady Critique** - Code review and quality assessment

### 🛠️ Tech Stack

- **Frontend**: React 18 + Vite
- **Editor**: Monaco Editor
- **UI**: Tailwind CSS + Framer Motion
- **Desktop**: Electron
- **AI Integration**: HeadySystems API
- **Design**: Sacred Geometry patterns

### 📦 Installation

```bash
# Clone the repository
git clone https://github.com/HeadySystems/HeadyAI-IDE.git
cd HeadyAI-IDE

# Install dependencies
npm install

# Development mode
npm run dev

# Build for production
npm run build

# Run Electron app
npm start
```

### 🎮 Usage

1. **Select AI Model** - Choose your preferred Heady AI model from the sidebar
2. **Open/Create Files** - Use the file explorer to manage your project
3. **Start Coding** - Edit files with Monaco Editor's powerful features
4. **AI Assistance** - Chat with AI assistant for help with coding, debugging, and more
5. **Enjoy the Experience** - Immerse yourself in the sacred geometry interface

### 🎨 Design Philosophy

HeadyAI-IDE incorporates sacred geometry principles throughout the interface:

- **Flower of Life** - Animated background pattern representing unity and creation
- **Metatron's Cube** - Geometric overlay symbolizing balance and harmony
- **Organic Movement** - Smooth animations and transitions
- **Cosmic Colors** - Deep blues, purples, and golds reflecting the universe

### 🔧 Configuration

The IDE supports various configuration options:

```javascript
// AI Model Configuration
const aiConfig = {
  defaultModel: 'heady-brain',
  apiEndpoint: 'https://headysystems.com/api/ai/chat',
  timeout: 30000,
  maxTokens: 4096
};

// UI Preferences
const uiConfig = {
  theme: 'dark',
  animations: true,
  sacredGeometry: true,
  fontSize: 14
};
```

### 🌐 API Integration

HeadyAI-IDE integrates with HeadySystems cloud services:

```javascript
// Example AI Chat API Call
const response = await fetch('https://headysystems.com/api/ai/chat', {
```
