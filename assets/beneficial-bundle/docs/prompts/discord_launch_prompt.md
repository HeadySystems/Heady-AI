# Discord launch prompt

Design a Discord-native launch kit for Heady.

Include:
- server icon directions
- welcome banner variants
- 4 role badge styles
- 3 embed card themes
- launch announcement copy
- short status lines for ongoing operations

Tone:
- luminous
- systems-native
- confident
- helpful

Avoid:
- cartoon energy
- gamer cliché overload
- unreadable neon spam
