# Skill Graph starter

Purpose:
- search skills
- find neighbor skills
- detect gaps
- support graph and card-grid UIs

This starter is aligned with MCP Apps because UI-bearing tools can expose embedded interfaces through `ui://` resources inside host clients ([MCP Apps](https://github.com/modelcontextprotocol/ext-apps)).
